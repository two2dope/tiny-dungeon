Cada herói possui sua própria trilha de poder (níveis 1 a 6). A soma de seus níveis determina o Poder Bélico Total da expedição, essencial para superar os Chefes das rodadas 3, 6 e 8.

Mecânica Central de Escolhas

O Destino Gravado em Seis Dados

A cada rodada, seis dados são lançados sobre a pedra fria: três brancos e três negros. Você deve escolher exatamente três deles para forjar o destino da rodada.

Movimentação Tática (Dado de Bota)

Concede até 2 passos no labirinto. Caminhar por salas já exploradas é seguro; salas novas ativam encontros imediatos.

Fase de Perigo (Regra dos 3 Crânios)

Se a rolagem inicial exibir 3 ou mais crânios, 1 ferimento coletivo é sofrido automaticamente antes do rascunho de ações.

Desfazer & Refazer Livre

Teste caminhos e combinações sem medo. O estado é totalmente reversível antes de clicar em "Confirmar Rodada".

export function calculateFinalGloryScore(input: ScoreInput): FinalScoreBreakdown {
  const { party, minionsGlory, bossGlory, gemsCount, itemsCrafted } = input;

  // 1 ponto de glória por nível alcançado nos 4 heróis
  const heroLevelsGlory =
    party.heroes.warrior.level +
    party.heroes.mage.level +
    party.heroes.cleric.level +
    party.heroes.rogue.level;

  const gemsGlory = gemsCount * 2;
  const itemsGlory = itemsCrafted * 2;
  const resurrectionPenalties = party.resurrections * 9; // -9 pts por morte

  const netGlory =
    minionsGlory + bossGlory + gemsGlory + itemsGlory + heroLevelsGlory - resurrectionPenalties;

  return { minionsGlory, bossesGlory: bossGlory, gemsGlory, itemsGlory, heroLevelsGlory, resurrectionPenalties, netGlory };
}
